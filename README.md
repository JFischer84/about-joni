# About Joni

A personal website where I share a bit about myself and my work as a developer.

## Deployed Version
Check it out here:
👉 [https://about-joni.vercel.app](https://about-joni.vercel.app)

## Tech Stack

- Next.js
- TypeScript
- Tailwind
- Testing Library + Jest
- Vercel

## Scripts

| Script | Description |
|--------|------------|
| dev    | Runs the development server on [http://localhost:3000](http://localhost:3000) |
| build  | Creates an optimized production build |
| start  | Starts the production server |
| test   | Runs all tests |
| lint   | Runs ESLint to check for code issues |
| format | Formats the code using Prettier |
